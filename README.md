## Core Operational Focus

The baseline hospital system focuses on:

- Reducing patient record duplication
- Preventing data entry errors at the point of input

## Main TQM Approach

**Prevent → Validate → Confirm → Log → Analyze → Improve**

Quality will be built into every data entry point rather than checked only after records are saved.
